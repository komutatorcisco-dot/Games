# Скелет для модели игрока из «фото → 3D» (Tripo, Meshy)

Сервис отдаёт модель без скелета, на ~1 млн точек. Эти три шага делают из неё модель для игры:
те же 20 костей, что у Балотелли (`prototypes/balotelli/motion.js`, `NAMES`), поэтому работают
и «Покрутить в 3D», и выход игрока с ходьбой и празднованием.

Требования к модели: игрок стоит прямо, руки в стороны и вниз (A-поза), ноги чуть врозь.

```
npm i @gltf-transform/cli@4 sharp     # один раз
pip install bpy==4.2.0                # Blender как библиотека, один раз
node dec.mjs 0.06                      # src.glb → low.glb: распаковка и облегчение (~70 тыс. точек)
python3 rig.py                         # low.glb → rigged.glb: поворот лицом вперёд, рост 1,85 м, скелет, веса
node pack.mjs rigged.glb out.glb       # WebP-текстуры (цвет 2048, остальное 1024) + meshopt, ~1,4 МБ
```

Как ставятся веса: автоматические веса Blender («bone heat») не работают на моделях из нейросетей
(поверхность из кусков). Поэтому делается цельная копия (voxel remesh 11 мм, ~25 тыс. граней),
веса считаются на ней и переносятся на исходную модель (Data Transfer), затем до 4 костей на точку.

Суставы находятся по форме тела (срезы по высоте): колени и щиколотки — центры ног на 28,5 % и 6 % роста,
бёдра — 50 % роста на ширине 5 % роста от центра, шея — самое узкое место на 80–90 %,
руки — главная ось точек дальше плеч; локоть и запястье — 40 % и 76 % длины от плеча до кончиков пальцев.

Проверка: `prototypes/balotelli/viewer.html?model=../player/out.glb` и `index.html?model=../player/out.glb`.

## Лицо игрока на общей модели (без платных сервисов)

Фото лица прямо (лучше крупное, ровный свет, прозрачный фон) «натягивается» по 478 точкам лица (MediaPipe Face Mesh)
и по контуру головы выше бровей (переносится и стрижка)
на лицо общей модели: глаза, нос и рот фото ложатся точно на глаза, нос и рот модели.

```
pip install mediapipe==0.10.14 scikit-image
python3 -m http.server 8765 &                       # из корня репозитория
node face-frame.cjs model-front.png                 # снимок головы модели спереди (один раз на модель)
python3 face.py фото.webp prototypes/player/faces/<игрок>.webp   # печатает цвет щёк → skin
```

В игре: `viewer.html?model=../player/player-mobile.glb&face=prototypes/player/faces/<игрок>.webp&ff=-0.1,0.1,0.82,1.02&skin=<цвет>`
(ff — кадр снимка в долях роста, как в face-frame.html).

Форма клуба: `&kit=футболка.шорты.гетры.надписи&num=10&name=ФАМИЛИЯ&stripes=111111&crest=img/clubs/<клуб>.webp`
(stripes — три полоски по плечам, crest — эмблема на груди слева).
