## Архитектурная проблема
Каждый скин в `css/skins.css` целиком переписывает кнопки и панели правилами `body[data-skin=…] … !important`
(~150 строк, у каждого скина своя копия). Поэтому любое улучшение приходится дублировать в каждом скине.

Решение для реализации: компоненты берут цвета из CSS-переменных (`--btn-top`, `--btn-bot`, `--btn-edge`, `--btn-ink`,
`--panel-top`, `--panel-edge`, `--bar-fill`, …), а скин задаёт только значения переменных. Геометрия и размеры —
одни на все скины. Старые `!important`-правила скина заменяются переменными постепенно, экран за экраном.
Второй системы оформления не появляется: это те же скины и те же классы (`.btn`, `.pc`, `.sr-b`, `.ps-cell`, `.kb-*`).

## Производительность
Все три направления — только градиенты и тени без `blur`, без постоянных анимаций. Рисованные иконки — SVG
(~1 КБ каждая), без загрузки картинок.
