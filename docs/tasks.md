# Jackson Games — все задачи по полочкам

Один список для обеих сессий. История и подробности каждого шага — `docs/product-plan.md`.
Кто делает: **☁️ облако** (эта сессия), **💻 ПК** (сессия на компьютере с Blender), **👤 ты** (решение или проверка на телефоне).
Статусы: ✅ готово · 🔧 в работе · ⏭ следующее · ❓ ждёт твоего решения · 💤 позже.

Правило зон, чтобы сессии не мешали друг другу:
- ☁️ облако — `prototypes/shot/` (футбол: матч 3 на 3, 11 на 11, «Моменты», тренировки), `js/fcm.js`, `css/fcm.css`, меню, викторины, магазин, экран загрузки.
- 💻 ПК — модель игрока, `js/playerkit.js`, анимации, `js/arena3d.js` (матч драфта, «Менеджер», фон меню), картинки в `tools/art`.
