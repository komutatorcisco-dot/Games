# Jackson Games: аудит и план (27.10.2026)

Цель: зашёл → вижу цель → играю в футбол и мини-игры → получаю футболиста → ставлю в состав → играю им.
Цикл: событие → задания → награда → состав → новые испытания и матчи. Один аккаунт, одна коллекция, одна экономика.

## Карта того, что есть (по коду, не по README)

### Работает
- **Аккаунт и сохранение.** Вход через Telegram (initData проверяется сервером). Всё сохранение (`Store.d`) уходит в
  облако одним файлом (`/save`, `/load`). При конфликте побеждает версия с бо́льшим числом трофеев.
- **Экономика.** Монеты (`Econ`/`Coins` в `js/core.js`), убывающая отдача за повторяемые игры, магазин, паки.
- **Коллекция.** `js/cards.js`: бронза, серебро, золото, легенды и «Джексон». Повторки превращаются в монеты, есть ИПК (`js/sbc.js`), паки (`js/packs.js`).
- **Состав.** «Мой состав» (`js/squad.js`): 11 из коллекции, химия. Матч там — симуляция XMatch, без управления.
- **Прогресс.**
  - `js/rewards.js`: трофеи, путь трофеев, паки за победы, сезонный пропуск, задания дня и недели.
  - `js/release.js`: игры открываются за трофеи.
- **Событие с наградой от сервера.** «Забытые легенды» (Балотелли, `/legend`):
  - сервер сам считает задания (драфт-тур, победы, итальянцы);
  - карточку выдаёт один раз;
  - при обрыве связи карточка возвращается;
  - потом walkout.
  Это готовый образец для глав.
- **Мини-игры.** Около 40 штук (угадайки, головоломки, драфт, аукцион, козыри и т.д.). Почти все сообщают
  результат в `Rewards.onEnd`, поэтому уже кормят трофеи и задания.
- **Онлайн (пошаговый).** Подбор соперника (`/mm`), комнаты через сервер (`/room`, пачки раз в 0,6–2 с), дуэль,
  драфт-тур, клубы.
- **Управляемый футбол** (`prototypes/shot/shot.js`, ~4200 строк, three.js), во фрейме внутри хаба.
  - Режимы: удары (штрафной / пенальти), «1 на 1» (`run`), «2 на 1» (`duo`), матч 3 на 3 и пробный 11 на 11.
  - Три урока новичка.
  - Карточки из коллекции влияют на характеристики (мягко). Матч 11 на 11 берёт схему из «Моего состава».
  - По ощущениям: удары и вратарь — норм, пасы — приемлемо, ведение — слабое место.

### Есть, но не связано с остальной игрой
- **Футбол — тупик.**
  - Виден только в тестовой версии (`CONFIG.stage`).
  - Не сообщает хабу результат: нет трофеев, монет, заданий, прогресса событий. Фрейм умеет только «выход» и «вибрация».
- **Два разных «матча составом».** Симуляция XMatch в «Моём составе» и управляемый матч. Симуляцию оставляем как менеджерский режим; нужно ясно различать их в интерфейсе, состав и коллекция — общие.
- **Ни одно задание не опирается на футбол.** Ни в пропуске, ни в событиях.
- **«1 на 1» и «2 на 1»** — бесконечные тренировки без цели, счёта и конца серии.
- **Шаблон события «Легенды»** жёстко прописан под Балотелли (константы `FL`). Глав, жетонов и выбора между путями нет.

### Требует исправления
- **Ведение мяча** (главное):
  - нет честного «касание → мяч катится → следующий шаг»;
  - смена направления без переноса веса;
  - мяч держится у ноги «помощью», а не толчками.
- **Безопасность наград.**
  - Монеты, карточки и паки считает телефон, сервер хранит файл целиком. Подделанное сохранение или двойная выдача не ловятся.
  - Защищены только легенды и платежи.
  - Для ценных наград событий нужна выдача сервером, как у легенд.
- **Серверная экономика уже начата, но не влита.**
  - PR №3 (архитектура), №4 (этап 1, резервные копии) и №5 (этап 2) открыты, №5 — черновик.
  - В PR №5: серверный кошелёк, инвентарь, неизменяемый журнал операций, атомарные паки и ИПК, `/reward` с защитой от повторной выдачи (`econ_claims`), восстановление покупок за звёзды.
  - Отдельный Worker только для стенда, флаги выключены, отстаёт от основной ветки на 47 коммитов.
  - Нигде не используется. Награды за футбол и события строить на нём (`/reward`), параллельную систему не делать.

  - `claude/amazing-faraday-ofy7um`: приглашения в тестовой версии ведут в тестовый Mini App.
  - `claude/forgotten-legends`: легенды только для проверяющих.
  - PR №7 и №8 (профиль в стиле Brawl Stars) открыты.

### Чего действительно не хватает
1. Режима **«Моменты»**: серия коротких атак с концом эпизода, счётом и результатом.
2. **Канала результата** из футбола в хаб (`postMessage` → `Rewards.onEnd` + задания события).
3. **Общего движка событий**: глава = 2–4 задания из разных режимов, жетон, награда главы, главная карточка.
   Делается обобщением «Легенд», не заменой.
4. **Входа «Продолжить событие»** на главной: ближайшая цель и награда.
5. **Реального онлайн-футбола.** Нынешний relay (обновления раз в 0,6–2 с) для управляемого матча не годится.
   Это отдельный этап: нужен свой канал реального времени (WebSocket / Durable Objects), предсказание и сверка.

## Как это устроено в FC Mobile (ориентир)
- **События из глав.**
  - Каждая глава: тренировки (skill games) + матчи со своими условиями. Награда — жетоны, монеты, сундуки.
  - Главы открываются по неделям.
  - В финале жетоны меняются на главного игрока на выбор (событие Champions: 8 клубных глав, 28 дней).
- **Три формата футбола.**
  - Skill games — навык.
  - **VS Attack** — матч только из своих атак: «бросает» сразу в атаку, счёт по голам, ~1,5–2 мин.
  - Полный матч H2H — отдельно.
  - Наши «Моменты» = соло-аналог VS Attack.
- **Без друга.** Всё основное проходится против ИИ. PvP — для рейтинга.

## Новый вид «как FC Mobile» — макет (27.10)

Решения пользователя: викторины становятся заданиями событий и ежедневных заданий; рынок игроков — позже,
отдельным этапом (экономика и сервер); сначала макет на телефоне, потом перенос остального.
Сделано (`js/fcm.js`, `css/fcm.css`, только лёжа, тестовая версия): своя оболочка во весь экран — шапка в ряду кнопок

(Моменты, 3 на 3, Менеджер, 11 на 11, Тренировки); «Команда» — поле лёжа и кнопки; «События» — путь главы

цены и награды не менялись; награды события пока не выдаются. Кнопка «Старый вид» возвращает прежнюю главную.
Дальше: открыть всё с первого входа (в FC Mobile нет «открытия разделов за трофеи»), прогресс и награды события
через сервер, внутренние экраны (состав, коллекция, пак) в том же стиле.
