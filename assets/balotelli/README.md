# Balotelli — передача материалов для Claude

Это отдельная ветка материалов, не готовое обновление игры. Не сливать и не публиковать автоматически.

## Начать здесь

- `balotelli-imported-motion.glb`: модель со скелетом, тремя встроенными текстурами и перенесённым клипом (~8,3 секунды). Около 15 МБ, 20 костей, около 50 тысяч полигонов.
- `balotelli-imported-motion.blend`: редактируемая сцена с перенесённой анимацией.
- `balotelli-rigged-prototype.blend`: модель с нашим скелетом до переноса FBX.
- `motion-source/source.fbx`: исходная анимация из пользовательского архива pallone-da-calciogiocatore.zip.
- `motion-review-*.png`: кадры проверки перенесённой анимации, не доказательство плавности всего клипа.

Исходник пользователя был без скелета, примерно 1,89 миллиона полигонов. Его несжатая копия source.blend (~81 МБ) осталась локально; для продолжения доступны обе редактируемые подготовленные сцены. Текстуры включены в GLB. Происхождение и лицензия модели/анимации пользователем ещё не уточнены; наличие в этой ветке не подтверждает права на коммерческое использование.

## Локальный просмотр

Из этой папки: `python -m http.server 8765`, затем открыть `http://localhost:8765/`. Страница index.html воспроизводит исходный перенесённый клип. Пользователь проверял её автономную версию в Chrome: модель двигалась.

Без сервера: `python build_standalone.py` создаёт Show-Balotelli.html со встроенными GLB и библиотекой. Открыть этот файл в браузере. Большие сгенерированные HTML не закоммичены — они дублируют исходники и модель.

## Важное: выход из пака НЕ готов

`walkout.html` — неудачный прототип: почти неподвижная модель, CSS-появление, проблемы кадрирования головы. Пользователь его отклонил. Не выдавать его за законченный выход. Перенесённый FBX содержит движения с поднятием ног, похожие на работу с мячом, а не ходьбу и празднование.

Нужен полноценный выход: несколько шагов вперёд с движением ног и рук, остановка, уверенное празднование с разведением рук. Анимировать скелет, а не только положение картинки/модели. Проверить контакт стоп с полом, плечи, локти, колени, полный рост в кадре на телефоне и компьютере. Добавить повтор и пропуск. Последняя предложенная переделка этого поведения ещё не реализована.

Доступны Three.js 0.170.0, GLTFLoader и BufferGeometryUtils. build_training.py показывает автономную сборку с import map/data URL. Можно использовать этот подход для новой 3D-сцены выхода. Исходники библиотек сохраняют свои комментарии об авторстве.

Кости: root, pelvis, spine, chest, neck, head; clavicle.L/R, upper_arm.L/R, forearm.L/R, hand.L/R, thigh.L/R, shin.L/R, foot.L/R. Перед процедурной анимацией восстановить bind pose и проверить реальные оси костей. При переносе FBX исправлялось различие горизонтальной bind pose источника и вертикального первого кадра; подробности в retarget_motion.py и diagnose_motion.py.

## Скрипты и следующий прототип

prepare_rig.py, fix_poses.py и retarget_motion.py документируют подготовку модели. Перед запуском прочитать скрипты и использовать копии сцен: они ожидают определённые имена объектов и сохраняют результаты рядом со скриптами. Blender использовался 5.2.2. Для просмотра/новой браузерной анимации повторять подготовку не нужно.

training.html + training-physics.mjs — ранний отдельный прототип игрока и мяча. build_training.py собирает Jackson-Training.html. `node test_training.mjs` проверяет базовую игровую математику. Полноценного бега ещё нет; сначала закончить выход Балотелли. Браузерная визуальная проверка этого прототипа не завершена.

В среде Codex Windows блокировала прямой запуск Blender; у пользователя вручную он запускался. Облачному Claude не нужны пути C: — все основные материалы здесь. Не отключать защиту ОС.

## Границы задачи

Эта передача не включает изменения экономики. Не менять production D1, основной Telegram webhook, не выполнять реальные платежи и не публиковать игру без отдельного разрешения пользователя. Локальные изменения этапа 3 экономики остались в другой рабочей копии.
