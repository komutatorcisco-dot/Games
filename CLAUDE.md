# Jackson Games — правила для Claude

Футбольные мини-игры и карточный клуб для Telegram-канала «Старики Джексоны» (Telegram Mini App).
Обычный сайт без сборки: `index.html` + `js/*.js` + `css/*.css`, сервер — один Cloudflare Worker (`server/worker.js`) с базой D1.
План, решения и история этапов — `docs/product-plan.md` (читать перед работой, дописывать после каждого шага).

## Ветки и выкладка
- Работать в `claude/ui-quality`. Каждый коммит пушить в три ветки: `claude/ui-quality`, `preview/redesign`,
  `claude/jackson-games-telegram-a3j08i`.
- `preview/**` → GitHub Actions выкладывает превью и **проверочный** сервер `jackson-games-staging` (это можно).
- `claude/telegram-channel-games-kj1xly` — основная ветка: пуш в неё **сразу обновляет рабочий сервер** (`worker.yml`).
  Трогать только по слову пользователя «выкладывай».
- Пул-реквесты — только если пользователь попросит.

## Нельзя без отдельного разрешения пользователя
- Класть в репозиторий токены, ключи, секреты.
- Трогать рабочую базу D1, вебхук бота, платежи (Telegram Stars), выдачу наград на сервере.
- Менять экономику: цены, состав и шансы паков, награды, начисление монет и трофеев.
- Трогать `assets/balotelli-handoff`.
- Запускать деплой рабочего сервера или публиковать основную версию.
Проверки сервера — только на staging (`?stage=1`, `js/config.js`).

## Устройство
- Экраны: `<section class="screen">` в `index.html`, переключает `Screens.show(id)` (`js/app.js`), текущий — `body[data-scr]`.
- Сохранение игрока: `Store.d` (`js/core.js`), копия на сервере.
- Карточки и паки: `js/cards.js` (`Cards.PACKS` — шансы), `js/packs.js` (открытие), `js/shopstars.js` (магазин, цены как в `server/worker.js`).
- Открытие разделов за трофеи: `js/release.js` (`ALL_OPEN = true` — сейчас всё открыто сразу).
- 3D: three.js r128 из `vendor/three.min.js`; `js/arena3d.js` — стадион, матч, фон меню (`backdrop`), детали для картинок (`parts`).
- Новый вид «как FC Mobile» (только лёжа, тестовая версия; старого вида больше нет, старая главная — только для вертикального экрана): `js/fcm.js` + `css/fcm.css`. Вкладки Играть · Команда ·
  События · Задания · Магазин; за меню живой 3D-стадион; «Команда» — карточки на 3D-газоне, нажатие — наезд камеры.
- Горизонтальный вид старых экранов: `css/land.css`. Все правила для лёжа — внутри
  `@media (orientation: landscape) and (max-height: 620px)`; вертикальный вид не ломать.

## Картинки
- Паки: `img/packs/pk{0..4}-{360,160}.webp`, режимы: `img/fcm/mode-*.webp` — 3D-рендеры, генераторы в `tools/art`
  (`python3 -m http.server 8765`, затем `node tools/art/render.js packs|modes`). Шрифты генератора — `tools/art/fonts`.
- Значки нового вида — SVG в `js/fcm.js` (`IC`), белые глифы.
- При правке JS/CSS менять `?v=` у файла в `index.html` (иначе Telegram отдаст старую версию из кэша).

## Проверка
- Синтаксис: `find js server tests -name '*.js' -not -path '*/vendor/*' -print0 | xargs -0 -n1 node --check`.
- Тесты: `node tests/<имя>.test.js`; запускать те, что касаются изменённых частей (`*-browser.test.js` — через Playwright).
- Вид: локальный сервер `python3 -m http.server 8765`, Playwright, окно 844×390 (лёжа), Chromium с `--use-gl=swiftshader`.
  Экономно: 1–2 скриншота на проверку.
- Перед пушем перечитать свой дифф; работать небольшими шагами, каждый шаг — отдельный коммит.

## Общение
- Пользователь пишет по-русски и читает с телефона: коротко, сначала результат, без жаргона.
- Если задача упирается в экономику или сервер — предложить и спросить, не делать молча.
