# Jackson Hub: игры канала «Старики Джексоны»

Футбольные мини-игры для Telegram-канала и TikTok [@oldjacksons2](https://www.tiktok.com/@oldjacksons2).
Обычный сайт без сборки и сервера: открывается по ссылке в любом браузере, позже подключается как Telegram Mini App.

## Игры

| Игра | Суть |
|---|---|
| **Аукцион** | Рубрика канала: у каждого 50 монет и 5 мест. Игроки выходят по одному, ставки по очереди (+1/+2/+5/пас). Если у кого-то уже 5 игроков, второй добирает остальных бесплатно. Побеждает пятёрка с большей суммой текущей формы (`js/form.js`: старт сезона 2026/27 — голы, передачи, травмы; обновлять раз в месяц). Вдвоём или против бота. |
| **Пас в ворота** | Бесконечный пазл. Мяч катится до упора; надо обвести защитников и забить вверх в ворота за минимум ударов (сколько ударов нужно на 3 звезды, не показывается). С 4-го уровня на поле партнёры (синие манекены): ворота закрыты, пока мяч не побывает у всех. С 8-го — отбойники, от которых мяч уходит под прямым углом. С 16-го — лужи, в которых мяч вязнет. Поле растёт до 8×11. Туры по 10 уровней. |
| **Полка головоломок** | 8 мини-игр с уровнями: Сортировка мячей (каждый уровень проверяется решателем; мяч перелетает дугой и мягко садится в колбу), Розыгрыш (поверни плитки, чтобы мяч прошёл по всем игрокам; плитки плавно поворачиваются, линия паса загорается), Перекрась поле, Пятнашки с эмблемами (кусочки можно тянуть пальцем, двигается весь ряд), Найди пару с лицами игроков, Филворд с фамилиями игроков клуба, 2048: Карьера (от Двора до Золотого мяча; плитки едут и сливаются с анимацией), Поп-ит (силиконовые пузырьки в форме эмблем клубов и фигур; можно вести пальцем, лист переворачивается). Код в `js/pz/`. |
| **Прорыв к воротам** | 3D-игра канала (`runner.html`), открывается прямо в хабе на весь экран, кнопка «← В хаб» возвращает назад. three.js r128 лежит рядом в `vendor/`, запасной вариант — CDN. |
| **Игрок дня** | Один футболист на день, одинаковый у всех (смена в полночь по МСК). 6 ступеней подсказок: страна и позиция → возраст и номер → лига → прошлые клубы → клуб сейчас → первая буква; фото с каждым шагом чётче. Каждая ошибка открывает подсказку. Монеты от 120 до 20, одна попытка в день, вторая — за 50 монет. Серия дней, кнопка «Поделиться» (строка с квадратиками для комментариев канала). Код в `js/daily.js`. |
| **Состав дня** | Как Missing 11: стартовый состав сборной с ЧМ-2026, видны только клубы и число букв. Впиши фамилии всех 11 (5 промахов, 3 подсказки-буквы). Ежедневно + тренировка. `js/ng/lineup.js` |
| **Футбольный Wordle** | Фамилия футболиста за 6 попыток, экранная клавиатура. После 3-го промаха — сборная, после 5-го — клуб. Ежедневно + тренировка. `js/ng/wordle.js` |
| **Требл дня** | Три вопроса в день: эмблема, куда перешёл, у кого выше рейтинг FC 27. `js/ng/treble.js` |
| **Ложная девятка** | 9 утверждений, 3 из них ложные — найди их (2 ошибки). Утверждения собираются из базы. `js/ng/false9.js` |
| **Связи** | Как Connections: 16 футболистов → 4 группы по 4 (клуб, сборная, страна). `js/ng/connect.js` |
| **Топ-10** | Как Tenable: назови всех из списка (бомбардиры АПЛ, чемпионы мира и Европы, «Золотой мяч», дорогие трансферы, составы клубов 2026/27). `js/ng/top10.js` |
| **Тепло-холодно** | Как Contextinho: каждая догадка получает место в рейтинге похожести на загаданного игрока. `js/ng/context.js` |
| **Кто я?** | Угадай футболиста по одноклубникам — от ранних клубов (сложно) к последним (легко). Одноклубники считаются по годам в карьерах. `js/ng/whoami.js` |
| **Связка** | Как Link Up: соедини двух футболистов цепочкой одноклубников. `js/ng/linkup.js` |
| **Рейтинг** | Как Club Rank: расставь пятёрку по году основания, рейтингу FC 27, стоимости, сумме трансфера. `js/ng/rank.js` |
| **Box2Box на время** | Сетка Тики-Така-Тоу одному на 3 минуты, ошибка −10 секунд. Режим `timed` в `js/ttt.js`. |
| **Бинго** | Карточка 4×4 (клубы, сборные, страны), игроки выходят по одному. `js/ng/bingo.js` |
| **Драфт** | Как SuperDraft: собери 11 по схеме 4-3-3 из троек, итог = рейтинг + сыгранность. `js/ng/draft.js` |
| **Козыри** | Как Pack 11: карты-футболисты против бота (рейтинг, стоимость, возраст, номер). `js/ng/trumps.js` |
| **VS 100** | Назови игрока под категорию, но не самого популярного у «толпы» из 100 соперников. `js/ng/vs100.js` |
| **Дартс 170** | Сбей 170 до нуля за 9 дротиков номерами на футболках игроков под категорию. `js/ng/darts.js` |
| **Угадай сборную по клубам** | Как в видео канала: на поле по схеме стоит настоящий стартовый состав сборной (ЧМ-2026, `js/nationxi.js`), вместо игроков — эмблемы их клубов сезона 2026/27. 22 сборные. Выбери страну из четырёх, подсказок нет. 3 жизни. |
| **Возьмёшь этого или другого?** | Рубрика канала. 10 версий клубов (Реал, Барселона, МЮ, Милан, Ливерпуль, Бавария, Ювентус, Челси, Арсенал, Интер), 150 легенд всех времён. Вдвоём — от вратаря до нападения каждому по очереди показывают одного игрока, второй скрыт: «Беру» или «Пропускаю» (тогда достаётся скрытый); в конце сравниваются матчи за клуб. Соло («Кто легендарнее?») — угадай, кто сыграл за клуб больше матчей. Числа — официальные матчи по Transfermarkt, округлённо. |
| **Угадай футболиста** | Нация, лига, клуб, возраст, позиция, номер — как в видео канала. 189 игроков. |
| **Угадай карьеру** | Клубы игрока по годам открываются по одному (как на box2box). Соло и «с другом». |
| **Угадай клуб** | Подсказки от сложной к простой: страна, цвета, год, прозвище, факт, стадион, город. 52 клуба, включая РПЛ. |
| **Куда перешёл?** | Игрок, откуда ушёл, год и сумма. Выбери клуб из четырёх. 3 жизни. |
| **Дороже или дешевле** | Сравни сумму трансфера с предыдущей. Одна ошибка — конец серии. |
| **Кто выше в FC 27?** | Две карточки игроков, у второй рейтинг EA FC 27 скрыт: выше или ниже? 81 игрок. |
| **Кто дороже?** | То же по рыночной стоимости Transfermarkt (2026). |
| **Тики-Така-Тоу** | Сетка 3×3, как на box2box: впиши игрока, который подходит под строку и столбец. Подсказки — клубы, сборные, страны чемпионатов («Играл в Италии», «MLS»), «Был в аренде», «6+ клубов». Три вида сеток: «Клубы», «Клубы и сборные», «Микс». Каждая сетка проверяется на решаемость. Соло и вдвоём (крестики-нолики). |
| **Дуэль** | Двое угадывают футболиста по очереди с одного телефона. |

Магазин (`js/shop.js`, вкладка внизу): запасная жизнь (50 монет — продолжить серию в «Угадай сборную» или +2 попытки в «Угадай футболиста»), паки испытаний для головоломок (250 монет: 10 сложных уровней со своими раскладками, монеты ×2, бонус 100 за весь пак), рамки аватара, темы карточек на главной, мячи в «Сортировке» (глянец, футбольные, эмблемы клубов). Лимиты: в аукцион и «Возьмёшь этого или другого?» 5 бесплатных игр в день, дальше по 20 монет.

Экономика монет (`Econ` в `js/core.js`): вход, колесо, сундук (+100), игры дня и первые звёзды уровней платят полностью. Повторяемые игры — полностью первые 200 монет за день, следующие 200 вполовину, дальше 10% (индикатор в магазине). Ориентир: игрок на 10–15 минут в день получает ~250–300 монет, активный — ~700. Вся косметика стоит 8100, паки — по 250, так что цели хватает на 2–5 недель. Цены рамок 400–1500, тем 400–1000, мячей 300–900.

Новые игры живут в `js/ng/`: общий экран, ежедневное «зерно» по московскому дню (`Day`), поле ввода и «Поделиться» — в `js/ng/core.js`. Подсказки в угадайках идут от сложных к лёгким.

Общее: короткое обучение «Как играть» при первом запуске каждой игры (и кнопка «?» в шапке), монеты (летят в кошелёк), бонус за вход серией (7 дней, от 30 до 100 монет), колесо удачи раз в день (до 150 монет), подсказки, звания и опыт, достижения, фоновая lo-fi музыка (синтезируется в браузере, выключается в профиле).

## Картинки

- Эмблемы 299 клубов лежат в `img/clubs`: Европа — из набора [luukhopman/football-logos](https://github.com/luukhopman/football-logos), Бразилия, Аргентина, MLS, Саудовская лига, Япония, Мексика и др. — из [JoseArroyave/football-logos](https://github.com/JoseArroyave/football-logos) (SVG, переведены в webp). Список в `CRESTS` в `js/media.js`.
- Флаги-эмодзи рисует шрифт `fonts/TwemojiCountryFlags.woff2` ([country-flag-emoji-polyfill](https://github.com/talkjs/country-flag-emoji-polyfill)) — без него Windows показывает буквы «PT», «NL».
- Лица 1288 игроков лежат в `img/players` (из набора [FIFA-Player-Faces](https://github.com/saihari/FIFA-Player-Faces), фото времён FIFA 17–22), соответствие «игрок → файл» в `FACES` в `js/media.js`.
- Сетки поп-ита в форме эмблем (`js/pz/popcrests.js`) нарезаны из этих же картинок: 10×12 клеток, по 4 цвета.
- Для тех, кого нет в наборе (молодые: Ямаль, Кубарси, Дуэ…), браузер пробует взять фото с Википедии (работает на GitHub Pages и в Telegram). Иначе — инициалы.

## Где править данные

- `js/nationxi.js` — стартовые составы сборных для «Угадай сборную по клубам» (формат: схема, затем «Фамилия|Клуб» от вратаря к нападению).
- `js/players.js` — 1494 игрока (сезон 2026/27). 216 сверены с новостями о трансферах лета 2026; ещё 1278 (рейтинг 76+) добавлены из базы EA SPORTS FC 27 ([EA_FC_ANALYSIS](https://github.com/LakshmiKanth11/EA_FC_ANALYSIS), составы на 12.09.2026) — у них номер 0 (неизвестен), и в играх про номера их не загадывают.
- `js/careers.js`, `js/careers2.js` — 324 карьеры для «Угадай карьеру» и «Тики-Така-Тоу». Названия клубов должны совпадать буква в букву.
- `js/tttcats.js` — страны чемпионатов (какой клуб в какой стране) и названия сборных для «Тики-Така-Тоу».
- `js/quizdata.js` — трансферы, клубы, рейтинги FC 27 (`FC27`) и стоимость (`VALUES`).
- `QUOTES` в `js/core.js` — реплики Данила и Саши.

## Как выложить по ссылке (GitHub Pages)

1. Влей ветку в `main`.
2. На GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root)** → Save.
3. Через минуту игра откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

Можно сразу открыть нужную игру, добавив в конец ссылки: `#pass`, `#guess`, `#career`, `#club`, `#transfer`, `#auction`, `#hl`, `#fc`, `#value`, `#nation`, `#pick`, `#legend`, `#ttt`, `#duel`, `#profile`.

## Telegram Mini App

Скрипт Telegram уже подключён: внутри Telegram игра растягивается на весь экран, работают кнопка «Назад» и вибрация.
Подключение: @BotFather → Bot Settings → Menu Button (или `/newapp`) → вставить ссылку с GitHub Pages.
