# Jackson Hub: игры канала «Старики Джексоны»

Футбольные мини-игры для Telegram-канала и TikTok [@oldjacksons2](https://www.tiktok.com/@oldjacksons2).
Это обычный сайт без сборки и сервера: открывается по ссылке в любом браузере, позже его можно подключить как Telegram Mini App.

## Игры

| Игра | Что делать |
|---|---|
| **Пас в ворота** | Пазл с бесконечными уровнями. Мяч катится, пока не упрётся в защитника или бровку. Нужно закатить его в ворота за минимум ударов. Уровни разбиты на туры по 10 штук (Дворовая лига → … → Чемпионат мира → Легенда 1, 2, …), каждый 10-й уровень — финал тура. |
| **Угадай футболиста** | Угадываешь игрока по нации, лиге, клубу, возрасту, позиции и номеру, как в видео канала. 8 попыток, подсказки за монеты. |
| **Дуэль** | Двое на одном телефоне угадывают по очереди. По умолчанию игроков зовут Данил и Саша, имена можно поменять. |

Общее для всех игр: монеты за победы, бонус дня, подсказки за монеты. Прогресс сохраняется в браузере игрока.

## Как править

- **База футболистов**: `js/players.js`. Одна строка — один игрок. Данные по сезону 2025/26: после трансферного окна проверь клубы и номера.
- **Реплики Данила и Саши** после побед и поражений: `QUOTES` в `js/core.js`.
- **Сложность пазла**: функция `generate` в `js/pass.js`.

## Как выложить по ссылке (GitHub Pages)

1. Влей ветку в `main`.
2. На GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root)** → Save.
3. Через минуту игра откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

Можно сразу открыть нужную игру: в конце ссылки добавь `#pass`, `#guess` или `#duel`.

## Telegram Mini App (потом)

Скрипт Telegram уже подключён. Внутри Telegram игра растягивается на весь экран, работают кнопка «Назад» и вибрация.
Чтобы подключить: в @BotFather → `/newapp` (или Bot Settings → Menu Button) → вставить ссылку с GitHub Pages.
