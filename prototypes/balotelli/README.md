# Выход Балотелли из пака — демо (v2)

Отдельная страница, **в игру не подключена**, наград не начисляет.
Открыть: `prototypes/balotelli/index.html`. Прошлая версия для сравнения: `v1.html`.

## Авторство
- **3D-модель Балотелли** (`balotelli.glb`, `balotelli-mobile.glb`) создана автором проекта в Blender
  и принадлежит проекту Jackson Games.
- **Анимация в этом демо** написана кодом с нуля (`motion.js`): ходьба, остановка, празднование и ожидание.
  Сторонние клипы движения не используются. Клип финтов, встроенный в исходный GLB, из облегчённой
  модели удалён. Права на сторонние анимации (например, из `source.fbx`) модель не охватывает,
  и в демо они не попадают.

## Сценарий: основной, ~8 с до кнопок
| время, с | что происходит |
|---|---|
| 0,15 | тёмная сцена, силуэт карточки, свет редкости нарастает по краю |
| 0,45 / 1,3 / 2,15 | нация → позиция → клуб или «Герой» (по ~0,85 с, крупными буквами) |
| 3,0 | вспышка, лицо карточки: рейтинг, фамилия, редкость |
| 3,6 | карточка уходит в угол |
| 3,8 → 6,6 | игрок выходит из глубины: 5 шагов и приставной, «осадка» после остановки |
| 6,8 → 7,5 | празднование: плечи расправлены, руки в стороны |
| 7,9 | кнопки «Повторить» и «Продолжить»; дальше — спокойное ожидание |

«Пропустить» доступна всё время.

## Данные карточки
`resolveCard()` в `walkout.js` ищет игрока в `CARD_LEGENDS` (`js/data/cards.js`).
Балотелли там нет, поэтому показывается **тестовая карточка**: рейтинг «??», позиция и клуб «—»
с подписью «нет в каталоге», ленточка «ТЕСТ».
- `?card=Уэйн Руни` — проверка на игроке из каталога (данные карточки настоящие, 3D-модель пока одна).
- `?hero=1` — тестовый вариант «Герой»; `?rar=gold|silver|bronze|legend|jack` — цвета редкости.

Результат (`RESULT`) заморожен до начала сцены. Пропуск, повтор и перезагрузка ничего не начисляют.

## Как проверить плавность на телефоне
Покадровая запись (`video/`) показывает **позы**, а не скорость: её делают перемоткой, поэтому
она плавная при любой производительности. Плавность на реальном устройстве покажет только запуск на нём:
1. Откройте `index.html?fps=1` на телефоне и досмотрите проход до кнопок.
2. Внизу появится строка: число кадров, средняя частота, 95-й процентиль кадра, «медленных» (>25 мс),
   «рывков» (>50 мс), худший кадр и плотность пикселей. «Повторить» обнуляет замер.
3. Хороший результат на 60 Гц: средняя частота ≥55 к/с, рывков 0–1 (первый кадр после загрузки модели
   может быть долгим).

## Файлы
- `walkout.js` — сцена, свет, частицы, карточка и надписи (всё — функции времени сцены), камера, замер `?fps=1`.
- `motion.js` — процедурная скелетная анимация: план шагов, IK ног, таз, руки, празднование, ожидание.
- `balotelli-mobile.glb` — облегчённая модель, 1,6 МБ (исходник `balotelli.glb` — 15,0 МБ):
  без встроенного клипа, Color 2048 px WebP, Normal/ORM 1024 px WebP, геометрия meshopt.
  Грузится только при открытии сцены, параллельно этапам раскрытия. `?model=balotelli.glb` — с исходником.

## Что сделано с движением
1. Встроенный клип не используется: это финты с мячом на месте, с «щелчками» ретаргета до 543°/с.
2. Стопы стоят на запланированных следах (IK), таз идёт по кривой через середину между следами.
   Поэтому продвижение совпадает с шагами и стопы не скользят.
3. Высота таза рассчитана заранее и сглажена; учтён подъём пятки. Покачивание 5–6 см, без провалов.
4. Углы стопы непрерывны (перекат пятка → носок), приставной шаг без скачка.
5. Походка: стопы ставятся почти на одну линию с разворотом носков ~7°, а не на ширине бёдер.
   Перенос веса на опорную ногу ~3 см, поворот и наклон таза, противоход груди.
6. Руки: мах ±24° с запаздыванием за ногами, плечо идёт вместе с рукой, локоть сгибается при махе
   вперёд и почти прям при махе назад.
7. Остановка: замедление, приставной шаг, короткая «осадка» в коленях и возврат корпуса.
8. Празднование: грудь и плечи расправлены, подбородок вверх, руки в стороны; затем плавный переход
   к ожиданию (дыхание, перенос веса, поворот головы).

## Отладочные параметры
- `?cam=side|front|back` — вид сбоку/спереди/сзади для оценки походки.
- В консоли: `__seek(t)`, `__play()`, `__T()`, `__probe(t0, t1, dt)`, `__frameCheck()`.

## Арена и встраивание в игру (ветка claude/forgotten-legends)
- `stage.js` — фон: трибуны полукругом, кольцо прожекторов с лучами, арка-ворота, из которых выходит игрок,
  золотой обод над сценой, вспышки камер, глянцевый пол с разметкой.
- `?embed=1&n=…&r=…&pos=…&nat=…&rar=…&series=…&crest=…&face=…` — режим для игры: данные карточки приходят из
  каталога игры (текст и пути к картинкам проверяются), кнопка «К карточке» сообщает игре о конце выхода.
  Выход ничего не выдаёт — карточку выдаёт сервер до запуска сцены.
- `tools/portrait.html` — рендер портрета «голова и плечи» для карточки из этой же модели (прозрачный фон).
