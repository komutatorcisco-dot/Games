# Выход Балотелли из пака (прототип)

Отдельная страница, в игру не подключена. Открыть: `prototypes/balotelli/index.html`
(на GitHub Pages — `/Games/prototypes/balotelli/`).

- Модель: положи `balotelli.glb` в эту папку (20 костей: root, pelvis, spine, chest, neck, head,
  clavicle/upper_arm/forearm/hand .L/.R, thigh/shin/foot .L/.R). Нет файла — показывается тестовый манекен
  с теми же костями.
- Другой файл: `?model=имя.glb`. Модель смотрит спиной к камере: `?face=-1`.
- Анимация — код в `walkout.js` (кости поворачиваются по направлениям в мировых координатах, поэтому
  исходная T/A-поза и оси костей из Blender не важны): появление из света → шаги к камере →
  остановка → «Why always me?» (руки вниз и в стороны, грудь вперёд) → дыхание.
- Кнопки «Пропустить» и «Повторить». Камера подстраивается под экран: голова и стопы всегда в кадре.
