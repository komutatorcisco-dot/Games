## Сценарий (~10 с до празднования, ~15 с вместе с ожиданием)
| время, с | что происходит |
|---|---|
| 0,25 | тёмная сцена, силуэт карточки, свет редкости нарастает по краю |
| 1,0 / 2,1 / 3,2 | нация → позиция → клуб или «Герой» (данные из каталога игры) |
| 4,3 | вспышка, лицо карточки: рейтинг, фамилия, редкость |
| 5,15 | карточка уходит к краю, освобождая место игроку |
| 5,6 → ~9,8 | 3D-Балотелли выходит из глубины: 4 шага разгона + 4 полных/тормозящих + приставной |
| ~10 | празднование: плечи расправлены, руки в стороны |
| ~12 → | спокойное ожидание: дыхание, перенос веса, поворот головы |

«Пропустить» доступна всё время, «Повторить» и «Продолжить» — в конце.

## Данные карточки
`resolveCard()` в `walkout.js` ищет игрока в `CARD_LEGENDS` (`js/data/cards.js`).
Балотелли там нет, поэтому показывается **тестовая карточка**: рейтинг «??», позиция и клуб «—»
с подписью «нет в каталоге», ленточка «ТЕСТ». Нация «Италия» — из данных «Угадай карьеру».
Проверить на игроке из каталога: `?card=Имя Фамилия`. Редкость теста: `?rar=gold|silver|bronze|legend|jack`.
Результат (`RESULT`) заморожен до начала сцены; пропуск, повтор и перезагрузка ничего не начисляют.

## Файлы
- `walkout.js` — сцена, свет, частицы, карточка и надписи (всё — функции времени сцены), камера.
- `motion.js` — процедурная скелетная анимация: план шагов, IK ног, таз, руки, празднование, ожидание.
- `balotelli-mobile.glb` — облегчённая модель, 1,6 МБ (оригинал `balotelli.glb` — 15,0 МБ):
  встроенный клип удалён, Color 2048 px WebP, Normal/ORM 1024 px WebP, геометрия meshopt.
  Модель грузится только при открытии сцены, параллельно этапам раскрытия.
- `?model=balotelli.glb` — открыть с оригинальной моделью.

## Откуда были рывки и что сделано
1. **Встроенный клип — не ходьба.** Единственный клип в GLB (8,33 с) — финты с мячом на месте,
   перемещения корня нет. Есть «щелчки» ретаргета: шаги между ключами до 21–25°, угловая скорость до
   543°/с (`shin.L` на 7,93 с), одновременные всплески на 1,70 / 2,90 / 3,93 с. → Клип не используется.
2. **v1: корень ехал отдельно от шагов** — стопы скользили 5,1 м на 2,6 м пути, таз прыгал
   (ускорение 174 м/с²). → Таз идёт по монотонному сплайну через середину между следами, стопы стоят
   на запланированных следах (IK), поэтому скорость тела совпадает с шагами.
3. **v1: «приземление» по самой нижней лодыжке** — опора переключалась скачком. → Высота таза
   рассчитывается заранее на сетке 1/120 с с учётом длины ног и сглаживается.
4. **Провал таза в двойной опоре** (найден на этой итерации: до 20 см) — шаг был длинный, а подъём
   пятки не учитывался в длине ноги. → Шаг короче, подъём пятки учтён, амплитуда 5–6 см.
5. **Скачок угла стопы в приставном шаге** (−22° → −9° за кадр, колено 1453°/с). → У каждого шага
   свои углы отрыва и постановки, переход непрерывен.
6. **Пол сцены резал игрока по поясу**: у модели стопы на y = −1. → Модель ставится на пол по габаритам.
7. **Анимации переключаются весами-функциями времени** (ходьба/празднование/ожидание плавно
   перетекают), без резких смен состояний; карточка и надписи тоже считаются от времени сцены.

## Проверки (скрипты-хуки в странице)
- `__probe(t0, t1, dt)` — позиции стоп/таза/головы, углы коленей и локтей.
- `__frameCheck()` — экранные координаты головы, стоп, рук, карточки, надписей и кнопок.
- `__seek(t)`, `__play()`, `__T()` — перемотка и тайминг.
